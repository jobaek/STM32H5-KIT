This repository covers Eclipse ThreadX and related middleware, such as ThreadX, NetXDuo, FileX, and USBX. 

The board used here is the STM32H5-KIT, a product from Higenis.

https://smartstore.naver.com/higenis/products/13180487365

https://github.com/dong-higenis/stm32h5-kit



Environment

STM32CubeMX : V6.17.0

STM32CubeIDE : V2.1.0

STM32CubeH5 : V1.6.0
